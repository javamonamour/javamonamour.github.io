--- layout: post title: "Extended Logging Format Fields (ELFF) in WebLogic" date: 2012-04-17T06:51:00.002+02:00 permalink: /2012/04/extended-logging-format-fields-elff-in.html blogger_id: "8656402278416333951" tags: ["log", "weblogic"] --- By default WebLogic logs this fields in the access.log:
date time cs-method cs-uri sc-status

Here is the MBean WebServerLogMBean.ELFFields

and here the entire documentation on the supported field identifiers.

c-ip

The IP address of the client.

s-ip

The IP address of the server.

Don't forget that in case of need you can define a Java class to provide extra ELF fields.

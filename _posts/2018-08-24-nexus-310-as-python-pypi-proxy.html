--- layout: post title: "Nexus 3.10 as Python pypi proxy" date: 2018-08-24T14:14:00.001+02:00 permalink: /2018/08/nexus-310-as-python-pypi-proxy.html blogger_id: "6476692817502613891" tags: ["nexus", "pypi", "python"] --- sudo yum -y update
sudo yum -y install python-pip
pip --help
pip -V
mkdir ~/.pip
cd .pip/
vi pip.conf

enter this:

[global]
index = http://localhost:8181/repository/pypi/
index-url = http://localhost:8181/repository/pypi/simple

Create a nexus Pypi proxy repo "pypi" pointing to https://pypi.org/ . Leave all the defaults as they are.

pip install lino-amici

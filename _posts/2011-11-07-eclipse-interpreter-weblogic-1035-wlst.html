--- layout: post title: "Eclipse: Interpreter: Weblogic 10.3.5 WLST Interpreter not found" date: 2011-11-07T10:12:00.000+01:00 permalink: /2011/11/eclipse-interpreter-weblogic-1035-wlst.html blogger_id: "4515079888285282864" tags: ["eclipse"] --- Apparently in Eclipse, if you Import an existing project with the "Oracle WebLogic Scripting Tools (WLST) Support" facet, this is not enough to have the facet fully configured in your new project.
You will get an error "Interpreter: Weblogic 10.3.5 WLST Interpreter not found".
Workaround: create the Utiliy project, enable the "Oracle WebLogic Scripting Tools (WLST) Support" facet and copy the code manually.

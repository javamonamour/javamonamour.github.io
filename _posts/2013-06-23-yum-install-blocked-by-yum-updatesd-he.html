--- layout: post title: "yum install blocked by yum-updatesd-he" date: 2013-06-23T15:28:00.000+02:00 permalink: /2013/06/yum-install-blocked-by-yum-updatesd-he.html blogger_id: "303172215928609750" tags: ["yum"] --- I was doing
yum install graphviz
and got the message
"Another app is currently holding the yum lock; waiting for it to exit... The other application is: yum-updatesd-he"

This:
rm -rf /var/run/yum.pid

did the trick and let me proceed.

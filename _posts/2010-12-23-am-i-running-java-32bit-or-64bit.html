--- layout: post title: "Am I running Java 32bit or 64bit?" date: 2010-12-23T20:59:00.001+01:00 permalink: /2010/12/am-i-running-java-32bit-or-64bit.html blogger_id: "2453649624876395895" tags: ["java64bit"] --- in doubt, run

java -version

for 32bit, it should tell you nothing:

java version "1.6.0_18"
Java(TM) SE Runtime Environment (build 1.6.0_18-b07)
Java HotSpot(TM) Client VM (build 16.0-b13, mixed mode)

for 64bit, you should get an explicit message:

java version "1.6.0_15"
Java(TM) SE Runtime Environment (build 1.6.0_15-b03)
Java HotSpot(TM) 64-Bit Server VM (build 14.1-b02, mixed mode)

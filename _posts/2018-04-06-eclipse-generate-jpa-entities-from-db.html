--- layout: post title: "Eclipse generate JPA entities from DB" date: 2018-04-06T23:21:00.000+02:00 permalink: /2018/04/eclipse-generate-jpa-entities-from-db.html blogger_id: "5140163053196339117" tags: ["JPA"] --- Unfortunately there doesn't seem to exist a tool to generate JPA Entities directly from SQL. Weird!
So you have to start by populating a real schema.

Create a Java project

Configure "Targeted Runtimes" with "Wildfly 11 Runtime"

Configure Project, Facets, and select JPA (ignore the "further configuration available")

Right-click on Project, you should see "JPA Tools", "Generate Entities from tables"

--- layout: post title: "Change JVM parameters for Managed Server" date: 2011-10-02T11:21:00.000+02:00 permalink: /2011/10/change-jvm-parameters-for-managed.html blogger_id: "7722057368034565288" tags: ["weblogic"] --- If you start the Managed server from a script, invoking startManagedWebLogic.cmd,
be aware that passing the JVM parameters like this:

set JAVA_OPTIONS=-Xms1024m -Xmx1024m

will NOT work, although they DO appear in the command line. They appear, but duplicate and it's only the first occurrence which matters.

This is the way to do it:

set USER_MEM_ARGS=-Xms1024m -Xmx1024m -Xloggc:ms1gc.log

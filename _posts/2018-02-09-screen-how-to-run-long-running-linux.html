example:

screen
CTRL-A c (create new window)
top
CTRL-A c (create new window)
ls
CTRL-A n (next window)
You are now back in “top”


Restart VDI

Login again

screen –r (reattach)



With screen you can also open several terminal sessions from the same login, and tab through them with CTRL-A n

Root cause is missing .EAR file on some server - and the Admin is unable to redeploy the file, no clue why.
The only way to recover is by stopping the failed deployments (use the script here) and restart the failed server.
OSB will regenerate the EAR and redeploy to all instances in the cluster.

See also /2012/06/weblogicmanagementdeploymentexception.html for a possible workaround.

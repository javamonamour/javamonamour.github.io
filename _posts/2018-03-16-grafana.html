--- layout: post title: "Grafana" date: 2018-03-16T01:07:00.000+01:00 permalink: /2018/03/grafana.html blogger_id: "3438610910802868765" --- Download zip for Windows here http://docs.grafana.org/installation/windows/

unzip to D:\pierre\downloads\, it will create a grafana-5.0.1

cd D:\pierre\downloads\grafana-5.0.1

run ./grafana-server.exe

open browser at:

http://localhost:3000/login

if you don't like port 3000, edit D:\pierre\downloads\grafana-5.0.1\conf\defaults.ini :

http_port = 3000

and reboot.

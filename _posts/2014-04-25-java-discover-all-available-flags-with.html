--- layout: post title: "Java, discover all available flags with PrintFlagsFinal " date: 2014-04-25T23:19:00.001+02:00 permalink: /2014/04/java-discover-all-available-flags-with.html blogger_id: "7138585070162288020" tags: ["JVM"] --- not many people know that you can get the list of all supported JVM flags with -XX:+PrintFlagsFinal

java -XX:+PrintFlagsFinal -version | grep -i gc

--- layout: post title: "JMC: how to capture details of caught and unlogged exceptions" date: 2015-11-08T23:57:00.001+01:00 permalink: /2015/11/jmc-how-to-capture-details-of-caught.html blogger_id: "7043614438258876032" tags: ["jmc"] --- It happens occasionally that inexperienced programmers catch an exception and ignore it, or they catch it and throw another exception without reporting the full details of the root cause.

This situation turns naturally in an operational nightmare.

But Java Mission Control can really help you out. Let´s run this code (remember the -XX:+UnlockCommercialFeatures -XX:+FlightRecorder ) : 
public class ThrowsException {
 public static void main(String[] args) {
  while (true) {
   try {
    Thread.sleep(1000);
    throw new Exception("ciao bella gioia");
   }
   catch (Throwable t) {
   }
  }
 }
}

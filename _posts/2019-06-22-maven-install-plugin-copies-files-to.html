--- layout: post title: "maven-install-plugin copies files to your local .m2 repo" date: 2019-06-22T16:13:00.000+02:00 permalink: /2019/06/maven-install-plugin-copies-files-to.html blogger_id: "1358061454489887548" tags: ["maven"] --- http://maven.apache.org/plugins/maven-install-plugin/usage.html

you can run this command from anywhere, no need for a pom.xml:


$ mvn install:install-file -Dfile=/c/pierre/downloads/apache-maven-3.5.3-bin.zip -DgroupId=pippo -DartifactId=pluto -Dpackaging=zip -Dversion=3.0

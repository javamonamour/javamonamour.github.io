--- layout: post title: "Running Centos on Windows" date: 2019-01-18T18:02:00.001+01:00 permalink: /2019/01/running-centos-on-windows.html blogger_id: "2099198501996222058" tags: ["centos", "docker", "hyperv"] --- once you have upgraded to Windows PRO, you can install https://docs.docker.com/docker-for-windows/install/ Docker for Windows

Then open your Git Bash shell and run:

winpty docker run --name centos -i -t -d centos

If the container is stopped, you can simply

docker start centos

and login again:

winpty docker exec -ti centos bash


So you can have a "REAL" Centos on Windows... cool...

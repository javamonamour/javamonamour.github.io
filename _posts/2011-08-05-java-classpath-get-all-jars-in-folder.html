--- layout: post title: "Java classpath: get all JARs in a folder" date: 2011-08-05T13:11:00.000+02:00 permalink: /2011/08/java-classpath-get-all-jars-in-folder.html blogger_id: "5776194239748064542" tags: ["classpath"] --- Perhaps not everybody know that

java -cp "lib/*" YourClassHere

builds a classpath with ALL the JARs in the lib folder. Cool! No more horrible shell scripts to dynamically build a CLASSPATH.

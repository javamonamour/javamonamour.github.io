--- layout: post title: "YAML parsing in Python with PyYAML" date: 2014-02-26T13:38:00.001+01:00 permalink: /2014/02/yaml-parsing-in-python.html blogger_id: "6455472204560483629" tags: ["python", "yaml"] --- I was looking for a simple way of validating YAML structures, so I did the following:
download http://pyyaml.org/download/pyyaml/PyYAML-3.10.tar.gz
tar xvfz PyYAML-3.10.tar.gz
cd PyYAML-3.10
python setup.py install
python
import yaml 
mydomains=yaml.load("""
domains:
  osbpl1do:
    soauser: soa
    optpath: /opt
  osbpl2do:
    soauser: soa2
    optpath: /opt2
  osbpl3do:
    soauser: soa3
    optpath: /opt3
""")
print mydomains
print mydomains['domains']
print mydomains['domains']['osbpl2do']

It works like wonder.

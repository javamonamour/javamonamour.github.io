Most likely you have entered a wrong database name, or unexisting user.... the bloody installation script will never give you the REAL reason, otherwise your life would be too simple.

If you use OracleXE, remember that the DATABASE is XE (and not the default ORCL), and that you should created manually the UDDIUSER user and grant it all privileges, I am not sure the installation script will create it for you.

--- layout: post title: "Git: Received HTTP code 407 from proxy" date: 2013-12-04T12:03:00.000+01:00 permalink: /2013/12/git-received-http-code-407-from-proxy.html blogger_id: "4087300174460657835" tags: ["git"] blogger_comments: - author: "Anonymous" date: 2014-11-07 html: "This really works. Type

git config --global http.proxy http://myusername:mypassword@proxy.acme.com:8080

where myusername is "domain\\username" and password is "yourpassword".

Then do git clone as usually. :)" --- I was cloning a git project: 

git clone https://github.com/jiaqi/jmxterm

and I got
fatal: unable to access 'https://github.com/jiaqi/jmxterm/': Received HTTP code 407 from proxy after
 CONNECT


just do

git config --global http.proxy http://myusername:mypassword@proxy.acme.com:8080

and it will work (inshallah)

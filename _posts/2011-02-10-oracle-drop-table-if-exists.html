--- layout: post title: "Oracle: drop table if exists" date: 2011-02-10T11:37:00.000+01:00 permalink: /2011/02/oracle-drop-table-if-exists.html blogger_id: "1946853740139021603" tags: ["db", "drop"] --- something quite annoying in Oracle is that if you do

drop table MYTABLE;

and the table doesn't exist, you get an error.

A workaround can be:

BEGIN
EXECUTE IMMEDIATE 'DROP TABLE MYTABLE';
EXCEPTION WHEN OTHERS THEN NULL;
END;

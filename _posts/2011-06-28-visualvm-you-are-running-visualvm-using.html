For the Eclise plugin it is important to configure the correct path in the preferences (just search for "visualvm")." --- you double click on visualvm and you get this message - without an explanation of how to use a JDK instead.
Bummer.

After some research I find out that
visualvm_132\visualvm_132\etc
contains a file
visualvm.conf
with an entry:

# default location of JDK/JRE, can be overridden by using --jdkhome <dir> switch
#jdkhome="/path/to/jdk"

I replace it with

jdkhome=C:/Oracle4/Middleware/jdk160_21

and it works....
